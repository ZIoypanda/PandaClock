## PandaClock 1.0.7

- Добавили удобную ручную расстановку цифр для формы «Пудж»: цифру можно зажать и перетащить в нужную клетку.
- Появились сохранённые профили раскладки Пуджа. Теперь можно сохранить несколько вариантов и быстро переключаться между ними.
- Профили Пуджа можно удалять через правый клик по сохранённому профилю.
- Редактирование раскладки стало понятнее: завершение теперь выполняется отдельной кнопкой «Готово» рядом с часами.
- Убрали лишнюю подсказку поверх циферблата, чтобы она не мешала настройке.
- В меню по правому клику на часы добавили кнопку «Настройки».
- Исправили перехват кликов окнами редактирования и сохранения профилей.
